# Contributors

Archer thrives thanks to our open-source contributors who build features, fix bugs, optimize performance, and improve documentation.

## How to Become a Contributor

1. Check our [GitHub Issues](https://github.com/abhishekkksharma/Archer/issues) labeled `good first issue` or `help wanted`.
2. Review our [Contributing Guide](/docs#getting_started/contributing) for branch naming conventions and coding standards.
3. Submit a pull request with your changes!

## Recognition

All contributors are credited in our repository and release notes. Whether you submit documentation fixes, architectural designs, UI polish, or backend enhancements, your contribution is deeply appreciated.
