# Projects in Archer

The Projects module forms the heart of Archer. Every software venture in Archer is organized into a Project workspace, encapsulating its AI blueprint, architectural specifications, tech stack configurations, execution roadmap, and live preview dashboard.

## Overview of Project Capabilities

- **Automated Blueprinting**: Submit an idea or specification to generate complete system architecture.
- **Tech Stack Advisory**: Explore, configure, and customize the technologies powering your project.
- **Milestone Roadmaps**: Track progress across phases, tasks, effort estimations, and dependencies.
- **Real-Time Assistant**: Chat with an AI assistant loaded with complete project context.
- **Live Preview Viewport**: Embed active web deployments directly within the workspace.
