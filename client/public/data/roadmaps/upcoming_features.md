# Upcoming Features

The Archer engineering roadmap is actively evolving. Here are key initiatives currently planned or in development:

## Planned Platform Enhancements

### 1. Two-Way GitHub Synchronization
- Automatically sync Archer roadmap tasks with GitHub Issues and Projects.
- Auto-close tasks upon merging corresponding pull requests.

### 2. Multi-Model LLM Selector
- Allow users to choose their preferred model provider (Anthropic Claude 3.7 Sonnet, OpenAI GPT-4o, Google Gemini 2.0 Flash) on a per-project basis.

### 3. Interactive Architecture Canvas Export
- Export generated architecture diagrams to SVG, PNG, and Mermaid.js markdown syntax.

### 4. Team Collaboration & Real-Time Sync
- Multi-user workspaces with live cursor presence and role-based permissions (Admin, Editor, Viewer).

### 5. Automated CI/CD Pipeline Generator
- Generate GitHub Actions workflows tailored to the project's selected tech stack and test configuration.
