# Projects Overview

Archer organizes your engineering workflows around discrete Projects. Each project acts as a single source of truth for architectural planning, technology selection, and milestone tracking.

## The Project Workspace

When you open a project, you are presented with a unified workspace containing:

### 1. Workspace Header
- **Project Title & Metadata**: Displays project name, target platform, current stage, and creation timestamp.
- **Progress Gauge**: Visual indicator showing completed vs remaining development tasks.
- **Repository & Live Deployment Links**: Direct links to configured GitHub repositories and live deployments.

### 2. Navigation Tabs
- **Overview**: High-level metrics, quick actions, and embedded live application viewport.
- **Analysis**: Codebase structure insights, component breakdown, and system responsibilities.
- **Architecture**: Interactive system architecture diagrams and data flow visualization.
- **Roadmap**: Phased milestones, task dependencies, effort hours, and execution priorities.
- **Tech Stack**: Frontend, Backend, Database, Auth, and third-party services.
- **Tasks**: Granular task tracker with status filters (Todo, In Progress, Done).
- **Assistant**: Context-aware AI chat assistant with project awareness.
- **Settings**: Configuration settings for project URLs, names, and environment parameters.
