# Creating Projects

Archer simplifies project initialization by turning your natural language ideas into comprehensive technical blueprints.

## Creation Workflow

1. **Open Dashboard**: Navigate to `/dashboard` after signing in.
2. **Click "New Project"**: Open the project creation modal.
3. **Specify Project Details**:
   - **Project Name**: Enter a descriptive title (e.g., "E-Commerce Microservices Platform").
   - **Description & Requirements**: Describe your application in detail. Include goals, user roles, core workflows, and any technical constraints.
   - **Project Type**: Select the closest category (Web Application, Mobile App, Desktop App, API Service, CLI Tool, AI/ML Project, Fullstack App).
   - **Experience Level**: Beginner, Intermediate, or Advanced (influences tech stack recommendations and roadmap detail).
4. **Generate Blueprint**:
   - Archer sends the prompt to the backend AI completion pipeline.
   - The engine returns validated architecture components, tech stack items, and roadmap phases.
5. **Explore & Customize**:
   - Once generated, your project workspace opens automatically.
   - You can fine-tune recommended technologies, reorder tasks, and invite team members.
